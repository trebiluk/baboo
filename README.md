# Baboo

Classroom floor-plan studio. Local-first. Dedicated to Dr. Donna Matteson.

Version: 1.0.11  
Theme: Stark — white + black, periwinkle flash.

## Run locally (no Vercel)

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

## Student files

Projects save as `.archworks.json` on the device (IndexedDB + download).  
No Google login inside the app.

## Stack

React + Vite + TypeScript + Konva + Zustand
